# exam-ocr

Claude Code plugin: folder of exam photos -> OCR (Claude vision) -> one Word/Markdown document.

## Install (local)
```
claude --plugin-dir ./exam-ocr
```
## Use
```
/exam-ocr:exam-ocr ~/Desktop/de-thi-toan-9 de-thi-toan-9
```
Or just say: "OCR thư mục ảnh này và gộp thành đề thi".

Optional: `brew install pandoc` (real Word equations for math).
